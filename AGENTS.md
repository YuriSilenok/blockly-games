# Правила работы над проектом

- Не запускать тесты без отдельной просьбы пользователя.
- После изменений создавать коммит и отправлять его в GitHub.
- Работать с готовыми сборками, не возвращать компиляцию.
- Документация (`pond/docs.html`) и справка уровня — разные элементы. При переводе документации менять только текст, сохраняя изображения и разметку.
- В справке уровня сначала показывать только новые для этого задания блоки, затем текст задания. Во втором задании новый блок — `scan`.
- На втором уровне для прохождения требуется блок `scan` в параметре расстояния блока `cannon`.
- Запуск уровня запрещён, пока не пройдены предыдущие уровни. При нажатии «Запустить программу» показывать предупреждение и не запускать игру.
