# Правила работы над проектом

- Не запускать тесты без отдельной просьбы пользователя.
- После изменений создавать коммит и отправлять его в GitHub.
- Работать с готовыми сборками, не возвращать компиляцию.
- Документация (`pond/docs.html`) и справка уровня — разные элементы. При переводе документации менять только текст, сохраняя изображения и разметку.
- В справке уровня сначала показывать только новые для этого задания блоки, затем текст задания. Во втором задании новый блок — `scan`.
- На втором уровне для прохождения требуется блок `scan` в параметре расстояния блока `cannon`.
- Запуск уровня запрещён, пока не пройдены предыдущие уровни. При нажатии «Запустить программу» показывать предупреждение и не запускать игру.
- Справка состоит из двух разделов: цитата документации о новых блоках с исходными изображениями, затем задание. Содержимое прокручивается при нехватке места.
- Рядом со «Справкой» находится «Сброс»: после подтверждения удаляет прогресс уровней только Pond Tutor в текущем браузере.
- Новые блоки уровней 1–4: cannon; scan; переменные; log. Тексты заданий задаются пользователем.
- Окно победы имеет тот же размер, что и справка; содержимое прокручивается, кнопки закреплены внизу справа.
- Для всех уровней проверять требования текущего задания к блокам перед запуском и засчитывать победу только для программы, прошедшей проверку. Для уровня 3 угол присваивается один раз общей переменной cannon и scan. На уровне 4 решение — связанная последовательность: переменная угла = число; отдельная переменная расстояния = scan(переменная угла); log(переменная расстояния); cannon(переменная угла, переменная расстояния). Имена переменных произвольные; каждое значение задаётся один раз.
- Прежнее задание 5 перенесено на уровень 15 вместе со сценой: требуется swim и победа тараном, использование активного cannon запрещено. Новое задание 5 объясняет продолжение движения после одной команды: решение содержит ровно один swim с числовым углом, без циклов и других блоков; в панели блоков доступен только swim.
- В документации и цитатах справки сохранять пробелы между обычным текстом и встроенными названиями команд в code.
- Уровень 6: игрок (50, 50), цели (80, 50) и (20, 50). Победа тараном. Решение строго по образцу: swim(0), пустой while(speed() > 0), swim(180). Сначала вправо, затем влево; условие сравнивает speed слева с нулём справа через >. Запрещены cannon и stop; новые блоки — speed, цикл «пока», сравнение.
