# Пруд: обучение и турнир команд

Готовые сборки Pond Tutor и Pond Duck сохранены без компиляции. Интерфейс и документация доступны на русском языке. Рабочий сайт: https://силенок.рф.

Обучение состоит из 15 экспериментов. Справка цитирует документацию с исходными изображениями новых блоков, затем описывает цель. Проверки учитывают изучаемую возможность и фактическую победу, не фиксируя числа, имена переменных, конкретный порядок или единственное решение. На уровнях тарана запрещена стрельба. Уровни 9–11 посвящены круговому поиску, выстрелу, тарану и догонялкам; 12–14 — поединкам с каждым типом противника; 15 — общей битве.

Вход в личную учётную запись обязателен перед обучением. Ученик выбирает логин и пароль при регистрации. Капитан создаёт команду и добавляет до двух зарегистрированных игроков по логинам: в команде от одного до трёх участников. Каждый участник, завершивший обучение, может отправлять её алгоритмы. Прогресс сохраняется в SQLite и доступен на разных устройствах. Перед сохранением сервер повторяет решение в изолированном процессе с исходным движком игры. После обучения открывается отправка алгоритма на турнир.

Место нового решения определяется бинарным поиском по турнирной таблице. Каждая встреча идёт до двух побед (не больше трёх боёв). Перед каждым боем выбираются случайные стартовые позиции с расстоянием не меньше 70 px на поле 400×400, то есть примерно 19,18 игровых единиц с учётом полей отрисовки. По истечении времени победитель определяется по оставшемуся здоровью; при равном результате победа в бою засчитывается алгоритму, отправленному раньше. Из повторных решений команды остаётся занявшее лучшее место.

В личном кабинете участник и администратор могут менять собственный пароль с подтверждением текущего. Сессии на других устройствах при этом завершаются. Капитан управляет названием и составом команды; участник может выйти из команды. Старые личные команды и результаты автоматически переносятся в новую схему без потери прогресса.

Панель `/admin` позволяет создавать и открывать/закрывать турниры, наблюдать текущий бой в реальном времени и просматривать таблицы. Исходный код ученику не отображается: работа ведётся с блоками.

## Запуск

Python 3.8, зависимости: `server/requirements.txt`. Из корня репозитория:

```sh
python -m venv .venv
.venv/bin/pip install -r server/requirements.txt
.venv/bin/python -m server.app
```

Приложение слушает `127.0.0.1:8000`. Настройки окружения и инструкция для VPS, HTTPS, резервного копирования и автообновления: [deploy/README.md](deploy/README.md).

GitHub Pages продолжает публиковать `appengine` существующим workflow. Статическая версия показывает главную страницу и направляет на основной домен для регистрации, обучения и турниров.

Клиентские изменения находятся в `appengine/pond/course.js`, `course-data.js`, `tournament-editor.js` и `appengine/portal`. Интеграция подключается к сохранённым `generated/compressed.js`; сборочная цепочка не используется. Серверные файлы `server/runtime/avatar.js` и `battle.js` исполняются напрямую в QuickJS и сохраняют исходную физику Pond.

Тесты запускаются только по отдельной просьбе владельца.
