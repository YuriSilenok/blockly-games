Документация по игре «Пруд»

Пруд

Углы

Направления на поле: 0° — вправо (восток), 90° — вверх (север), 180° — влево (запад), 270° — вниз (юг). Углы отсчитываются против часовой стрелки и повторяются через полный оборот: −90° — вниз, 450° — вверх.

Выстрел — cannon

cannon(angle, range)

Функцияcannon()стреляет в заданном направлении на заданное расстояние. Первый параметр — угол, второй — расстояние до точки попадания. Направление выстрела не зависит от поворота утки. Дальность — от 0 до 70 метров; большее значение ограничивается до 70.

После выстрела пушка перезаряжается примерно секунду. Если вызватьcannon()в это время, выстрела не будет. cannon()Результатtrueпри успешном выстреле иfalseво время перезарядки.

Поиск противника — scan

scan(angle)
scan(angle, width)

Функцияscan()включает радар и возвращает расстояние до ближайшего противника в заданном направлении. Угол не зависит от поворота утки. Потонувшие утки не обнаруживаются. Если противника нет, возвращаетсяInfinity— бесконечность.

Второй, необязательный параметрscan()задаёт ширину луча радара от 1° до 20°. Можно начать с 20° для быстрого поиска, а затем сужать луч для более точного прицеливания. По умолчанию ширина — 5°. Этот параметр доступен только в JavaScript.

Движение — swim

swim(angle)
swim(angle, Скорость)

Функцияswim()начинает движение утки. Она продолжает плыть в указанном направлении, пока программа не изменит команду.

Второй, необязательный параметрswim()задаёт скорость от 0 (остановка) до 100 (максимум). Менять направление можно при скорости не выше 50. По умолчанию скорость — 50. Этот параметр доступен только в JavaScript.

Столкновение с краем пруда повреждает утку. При столкновении с другой уткой повреждаются обе. Чем выше скорость, тем сильнее повреждения.

Остановка — stop

stop()

Функцияstop()останавливает утку. До полной остановки она некоторое время замедляется.Это равнозначно вызовуswim()со скоростью 0.

Координаты

  

getX()
getY()

ФункцияgetX()иgetY()возвращают горизонтальную и вертикальную координаты утки. Значения — от 0 до 100, начало отсчёта — левый нижний угол. Центр поля — (50, 50).

Скорость

speed()

Функцияspeed()возвращает текущую скорость утки: от 0 (стоит) до 100 (максимум). По резкой остановке можно обнаружить столкновение.

Здоровье

health()

Функцияhealth()возвращает здоровье утки: от 0 (потонула) до 100 (полное здоровье). Сохраняй здоровье в переменной и сравнивай с текущим значением: уменьшение означает, что утка получила повреждения.

Восстановить здоровье нельзя.

Отладка

log()

Функцияlog()выводит заданное число в консоль браузера. Это помогает наблюдать за значениями и находить ошибки в программе.

Логика

Условия

if (condition) {
  statements
}


if (condition) {
  statements
} else if (condition) {
  statements
}


if (condition) {
  statements
} else {
  statements
}

Если условие истинно, выполняются вложенные команды. ПослеУсловияможно добавить несколько ветвейelse ifс другими условиями, а в конце — необязательную ветвьelse, которая выполняется, если ни одно из предыдущих условий не подошло.

Сравнения

==    !=    <    <=    >    >=

Эти выражения сравнивают два числа и возвращаютtrueилиfalse. Доступны шесть операторов сравнения:

Оператор Пример Результат
Равно 5 == 10 false
Не равно 5 != 10 true
Меньше 5 < 10 true
Меньше или равно 5 <= 10 true
Больше 5 > 10 false
Больше или равно 5 >= 10 false

Использование!=может привести к ошибке при сравнении дробных чисел. Например, эта программа должна доплыть до отметки 50 и остановиться:

while (getY() != 50) {
  swim(90, 50);
}
stop();

Программа может не остановиться: значениеgetY()может измениться с 49,4 сразу на 50,6. Точного равенства 50 не возникнет, и цикл продолжится. Лучше проверять, что координата меньше 50:

while (getY() < 50) {
  swim(90, 50);
}
stop();

«И» и «или»

&&    ||

Логическое «и» обозначается оператором&&. Он возвращаетtrue, только если оба условия имеют значениеtrue. В примере выстрел происходит, только если расстояние больше 5 и меньше 70:

if (range > 5 && range < 70) {
  cannon(angle, range);
}

Логическое «или» обозначается оператором||. Он возвращаетtrue, если хотя бы одно условие имеет значениеtrue. В примере утка останавливается вблизи любого края пруда:

if (getX() < 10 || getX() > 90 ||
    getY() < 10 || getY() > 90) {
  stop();
}

Логические значения

true    false

Значениеtrueозначает истину. В цикле while оно позволяет повторять команды бесконечно. Значениеfalseозначает ложь.

Циклы

Цикл «пока»

while (condition) {
  statements
}

Цикл повторяет вложенные команды, пока условие истинно. Например, этот цикл постоянно стреляет влево:

while (true) {
  cannon(180, 50);
}

А этот цикл стреляет влево, пока противник находится в пределах дальности пушки:

while (scan(180, 5) <= 70) {
  cannon(180, scan(180, 5));
}

Математика

Числа

123

Числа задают расстояния, углы и счётчики. Они могут быть отрицательными (−360), дробными (3.14159) и большими (9007199254740992). Дробная часть в программе отделяется точкой. Особое значение бесконечности —Infinity.

Не используй разделители тысяч: пиши 9000, а не 9,000.

Арифметика

+    -    *    /

Эти операторы принимают два числа и возвращают одно. Доступны четыре арифметических действия:

Оператор Пример Результат
Сложение 3 + 4 7
Вычитание 3 - 4 -1
Умножение 3 * 4 12
Деление 3 / 4 0.75

Тригонометрия

Math.operation(Числа)

Эти функции принимают число и возвращают число. Доступны восемь функций:

Функция Пример Результат
Квадратный корень Math.sqrt(25) 5
Модуль числа Math.abs(-25) 25
Синус Math.sin_deg(30) 0.5
Косинус Math.cos_deg(30) 0.86
Тангенс Math.tan_deg(30) 0.577
Арксинус Math.asin_deg(0.5) 30
Арккосинус Math.acos_deg(0.866) 30.003
Арктангенс Math.atan_deg(0.577) 29.985

Эти тригонометрические функции специально добавлены в игру «Пруд» и работают с градусами. Стандартные функции JavaScript используют радианы.

Случайные числа

Math.random()

Функция возвращает случайное число от 0 включительно до 1 не включительно. Для большего диапазона умножь результат на нужное значение. Пример случайного угла:

var angle = Math.random() * 360;

Переменные

Присваивание

var name = value;

Сохраняет значение, обычно число, в переменной. Выбирай понятное имя, напримерrangeилиangle.

Имена переменных чувствительны к регистру: например,angleиAngle— разные переменные. Для простоты используй латинские буквы и цифры. Имя не должно начинаться с цифры.

Функцияvarпри первом присваивании объявляет переменную. При следующих присваиваниях его можно опустить.

Увеличение значения

name += Числа;

Это короткая запись прибавления числа к значению переменной. Следующие две строки равнозначны:

angle += 10;
var angle = angle + 10;

Не применяй+=к переменной без начального значения. При необходимости присвой ей 0 в начале программы.

Получение значения

name

Возвращает значение, ранее сохранённое в переменной.
