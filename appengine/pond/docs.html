Справка по игре «Пруд»

Управляй уткой с помощью блоков или программы на JavaScript. Названия команд, например cannon и scan, нужно писать латинскими буквами.

Управление уткой

Углы и направления

Направление задаётся углом в градусах. 0° (или 360°) — вправо, 90° — вверх, 180° — влево, 270° — вниз. Углы увеличиваются против часовой стрелки. Направление отсчитывается относительно поля, независимо от того, куда повёрнута утка.

После полного оборота направления повторяются: −90° означает вниз, а 450° — вверх.

Выстрел — cannon

cannon(угол, расстояние)

Первый параметр задаёт направление выстрела, второй — расстояние от утки до точки попадания. Допустимая дальность — от 0 до 70 метров. Значение больше 70 ограничивается до 70.

Например, cannon(90, 35) стреляет вверх на расстояние 35. После выстрела пушка перезаряжается примерно секунду. Во время перезарядки команда не стреляет.

Функция возвращает true, если выстрел произошёл, и false, если пушка ещё перезаряжается.

Поиск противника — scan

scan(угол)

Радар ищет ближайшего противника в указанном направлении и возвращает расстояние до него. Потонувшие утки не учитываются. Если цель не найдена, результат — Infinity (бесконечность). Полученное расстояние можно передать вторым параметром в cannon.

В JavaScript доступен второй параметр: scan(угол, ширина). Ширина луча — от 1° до 20°, по умолчанию 5°. Широкий луч удобен для быстрого поиска, узкий — для точного прицеливания. В блоках этого параметра нет.

Движение — swim

swim(угол)

Утка начинает плыть в указанном направлении и продолжает движение, пока программа не изменит команду. Столкновение с краем пруда повреждает утку. При столкновении двух уток повреждаются обе. Чем выше скорость, тем сильнее повреждения.

В JavaScript можно задать скорость: swim(угол, скорость). Скорость меняется от 0 до 100, по умолчанию — 50. Изменять направление можно только при скорости не выше 50. В блоках отдельного параметра скорости нет.

Остановка — stop

stop()

Утка постепенно замедляется до полной остановки. Это соответствует вызову swim со скоростью 0.

Координаты — getX и getY

getX()
getY()

getX() возвращает положение по горизонтали: 0 — левый край, 100 — правый. getY() возвращает положение по вертикали: 0 — нижний край, 100 — верхний. Центр поля — (50, 50).

Скорость — speed

speed()

Возвращает текущую скорость: от 0 (утка стоит) до 100. Резкое падение скорости до нуля может означать столкновение.

Здоровье — health

health()

Возвращает здоровье: 100 — полное, 0 — утка потонула. Сохраняй предыдущее значение в переменной и сравнивай с текущим, чтобы заметить попадание. Восстановить здоровье нельзя.

Отладка — log

log(число)

Выводит число в консоль браузера. Используй эту команду, чтобы наблюдать за значениями и искать ошибки в программе.

Логика

Условия — if, else if, else

Блок «если» выполняет вложенные команды, когда условие истинно. Дополнительные ветви «иначе если» проверяются по порядку. Ветвь «иначе» выполняется, если ни одно условие не подошло.

if (scan(90) <= 70) {
  cannon(90, scan(90));
} else {
  swim(90);
}

Сравнения

ОператорЗначение
==Равно
!=Не равно
<Меньше
<=Меньше или равно
>Больше
>=Больше или равно

Сравнение возвращает true (истина) или false (ложь). Координаты могут быть дробными: утка может перейти с 49,4 сразу на 50,6. Поэтому для движения до отметки 50 используй условие «меньше 50», а не «не равно 50».

«И», «или» и логические значения

&& («и») требует, чтобы оба условия были истинны. || («или») требует хотя бы одного истинного условия. true означает истину, false — ложь.

if (getX() < 10 || getX() > 90) {
  stop();
}

Циклы

Повторение — while

Цикл «пока» повторяет вложенные команды, пока условие истинно. Условие проверяется перед каждым повторением. Цикл while (true) повторяется бесконечно.

while (true) {
  cannon(180, 50);
}

Этот пример постоянно стреляет влево на расстояние 50. Следующий стреляет, пока радар видит противника в пределах дальности пушки:

while (scan(180) <= 70) {
  cannon(180, scan(180));
}

Математика

Числа

Числа задают углы, расстояния и счётчики. Они могут быть отрицательными и дробными. В программе дробная часть отделяется точкой: 3.14159. Разделители тысяч не используются: пиши 9000. Infinity означает бесконечность.

Арифметика

+ складывает, - вычитает, * умножает, / делит. Например, 35 + 10 даёт 45.

Тригонометрия

Функции Math.sin, Math.cos и Math.tan вычисляют синус, косинус и тангенс. Math.asin, Math.acos и Math.atan выполняют обратные операции. Math.atan2(y, x) определяет угол по двум координатам, Math.sqrt вычисляет квадратный корень.

В игре «Пруд» тригонометрические функции работают с градусами. В обычном JavaScript используются радианы.

Случайные числа

Math.random() возвращает случайное число от 0 включительно до 1 не включительно. Умножь результат на 360, чтобы получить случайный угол:

var angle = Math.random() * 360;

Переменные

Создание и присваивание

Переменная хранит значение. Выбирай понятные имена: например, angle для угла и range для расстояния. В блоках создай переменную через категорию «Переменные» и используй блок присваивания.

var angle = 90;
var range = 35;

Имена чувствительны к регистру: angle и Angle — разные переменные. Для простоты используй латинские буквы и цифры; не начинай имя с цифры. При первом присваивании используй var, при последующих его можно опустить.

Изменение и чтение

Чтобы получить сохранённое значение, используй имя переменной. Запись angle += 10 увеличивает угол на 10 и равнозначна angle = angle + 10. Перед изменением переменная должна получить начальное значение.

cannon(angle, range);
angle += 10;

Функции

Функция объединяет команды, которые удобно выполнять вместе. Создай её в категории «Функции», задай имя и при необходимости параметры. Затем добавь блок вызова в программу. Функция с результатом возвращает вычисленное значение.

function fireUp(range) {
  cannon(90, range);
}
fireUp(35);

В этом примере функция fireUp стреляет вверх, а параметр range задаёт дальность выстрела.
